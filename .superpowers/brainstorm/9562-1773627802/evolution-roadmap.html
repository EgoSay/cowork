AI 协作进化引擎 — 迭代路线图

从最小闭环到完整进化系统，四阶段递进交付

Phase 1: 感知闭环 ← 当前

目标：看见 + 理解 + 手动标记

感知
  • 扫描 Claude Code 项目
  • 解析会话元数据
  • 首条消息 + 时间戳
  • 消息数 / Token 用量
认知
  • 会话效率面板
  • 每日会话数趋势
  • 平均迭代轮次
  • Token 消耗热力图
进化
  • 会话手动标注
  • 标签系统（高效/踩坑/模板）
  • 标注数据持久化
  • 按标签筛选回顾

交付物：项目浏览器 + 会话列表 + 效率面板 + 标注系统

Phase 2: 认知深化

目标：自动识别模式，量化协作质量

模式识别
  • 会话分类：feature / debug / refactor / explore
  • 自动检测"反复修正"模式（迭代次数异常）
  • 识别高效开场 prompt 结构
  • 工具使用频率分析（哪些工具你最依赖）
质量度量
  • 协作效率指数（目标达成 / Token 消耗）
  • 首次正确率（一次命中 vs 多轮修正）
  • 按项目/任务类型对比效率
  • 周报：本周 vs 上周协作质量趋势

依赖 Phase 1 的标注数据作为训练信号 + JSONL 深度解析

Phase 3: 进化引擎

目标：从历史中自动提取可复用经验

经验提取
  • 从"高效"标注会话提取 prompt 模板
  • 从"踩坑"标注会话提取避坑清单
  • 自动生成个人协作最佳实践文档
  • 跨项目经验关联（相似任务的不同解法）
上下文延续
  • 项目级知识摘要（自动维护）
  • 会话间上下文桥接建议
  • 智能 CLAUDE.md 生成/更新建议
  • 新会话自动注入相关历史摘要

需要调用 AI API 做内容分析 — 复用已有的 Provider 模块

Phase 4: 协作增强

目标：主动介入，实时提升协作质量

实时辅助
  • 会话实时监测（通过 watch JSONL）
  • 迭代次数告警："已修正 5 轮，建议换策略"
  • 上下文膨胀提醒：Token 接近窗口上限
  • 相似历史推荐："上次遇到类似问题时..."
生态扩展
  • 支持 Codex / Cursor / Trae 会话
  • 跨工具协作效率对比
  • 团队协作模式（共享最佳实践）
  • 插件系统：自定义分析维度

最终形态：从被动记录到主动进化的 AI 协作副驾驶

阶段依赖关系

P1: 感知闭环 → P2: 认知深化 → P3: 进化引擎 → P4: 协作增强
P1 → P2: 标注数据是模式识别的训练信号
P2 → P3: 模式识别结果驱动经验提取策略
P3 → P4: 提取的经验库支撑实时推荐

关键架构约束

● P1-P2 纯本地 — 不依赖外部 AI API，纯文件解析 + 本地统计
● P3 引入 AI — 经验提取需要 LLM，复用已有 Provider 模块
● P4 实时性 — 需要 file watcher 机制，从"查询式"升级为"推送式"
● 全程无数据库 — 延续项目哲学，文件系统 + 内存索引 + TOML/JSON 持久化
