Phase 1: 感知闭环 ← 当前

最小完整闭环：看见 → 反思 → 标记 → 回顾

感知
  • Claude Code 项目扫描
  • 会话元数据解析
  • 首条消息 + 时间戳 + 消息数
  • 复用 Usage parser 的 Token 数据
认知
  • 基础效率面板
  • 每日会话数 + 消息轮次
  • Token 消耗趋势（引用 Usage）
  • 项目活跃度排序
进化
  • 会话闪卡 + 一键标注
  • 标签：高效 / 踩坑 / 模板
  • 晨间焦点（3 数字 + 留白）
  • 按标签筛选回顾
学科原理映射
历史学 — 标注行为本身即刻意练习。闪卡追问"第 N 轮修正是否可避免"，不只展示数字
心理学 — 零摩擦标注（一键）降低行为门槛。Progress Principle：让每天的微小进步可见
人类学 — 晨间焦点 = 开启协作的仪式。不是"看报告"，是"准备进入状态"
神经科学 — 晨间焦点留白 50%，激活默认模式网络，让用户自己产生连接

Phase 2: 认知深化

自动识别模式，量化协作质量，建立进化可见性

模式识别
  • 会话自动分类（feature/debug/refactor）
  • 高迭代会话检测（反复修正模式）
  • 高效 prompt 结构识别

质量度量
  • 协作效率指数
  • 按任务类型的成熟度分级
  • 首次正确率趋势
  • 12 周进化轨迹图
潜移默化
  • 周进化报告（规则生成）
  • 上下文护栏（踩坑提醒）
  • 意外模式发现高亮
  • 探索/利用阶段提示
学科原理映射
神经科学 — 意外模式发现触发多巴胺，比确认已知趋势强 3-4 倍。优先展示"你没注意到的进步"
AI 智能 — 探索/利用检测：debug 成熟度高 → "利用已验证模式"；UI 成熟度低 → "继续实验"
历史学 — 军事 AAR 模型：周报结构 = 预期/实际/差异/教训，即时反思效果最佳
心理学 — 成长型心态话术：一切指标用"增长"框架呈现，从不用"失败"框架

架构约束 & 技术边界

P1 纯本地，文件系统 + TOML 持久化，不依赖 AI API ~2 周 P2 纯本地，规则引擎做模式识别，统计学方法做趋势分析 ~2 周 P3 引入 AI API（复用 Provider 模块），本地缓存提取结果 ~3 周 P4 file watcher 机制，从查询式升级为推送式，多工具扩展 ~3 周
全程无数据库 — 延续项目哲学：纯文件系统 + 内存索引
标注数据：~/.cowork/annotations.toml（P1-P2）
提取结果：~/.cowork/insights/（P3 缓存）

核心风险 & 缓解

R1 JSONL 文件巨大（单文件可达数 MB），扫描慢 增量扫描 + mtime 过滤 + 只读头部 N 行提取元数据 R2 标注摩擦导致用户放弃标注 一键标注 + 闪卡自动弹出 + 默认"无标注"也不影响基础功能 R3 规则引擎模式识别准确率低 P2 先用简单规则（迭代次数 > 阈值），P3 用 AI 替代 R4 进化指标缺乏真实感，变成虚荣指标 所有指标绑定具体可行动建议，不展示无意义数字
